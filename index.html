FREE vs PRO 기능 비교

버튼으로 화면의 기능만 전환합니다. 실제 회원가입·결제·유료 권한 검증 기능은 없습니다.

FREE

기본 번호 생성 · 합계/AC 표시 · 클릭형 기본 진단 · 기존 조건 필터 유지

PRO 체험

합계·AC의 정확한 조합 분포 · 과거 결과 비교 · 세부 AC 상한 · 원클릭 조건 프리셋

※ 무료/유료 차이는 분석 도구의 편의성입니다. 번호마다 1등 확률은 동일하며 PRO도 예측 능력을 제공하지 않습니다.

조건별 번호 조합 생성기

고정번호와 제외번호를 선택해 다양한 조합을 만들 수 있습니다.

생성 조건

반드시 포함할 번호, 최대 6개
조합에서 제외할 번호
PRO 체험추가 조건 · AC 범위와 프리셋

AC 범위는 조합의 간격 구조만 제한합니다. 당첨확률 개선이나 번호 예측은 아닙니다.

완전 무작위: 1~45에서 서로 다른 6개를 공정하게 추출합니다. 고정·제외 조건을 설정하면 해당 조건 안에서만 선택합니다.

생성된 번호

번호 생성하기를 누르면 이곳에 조합이 표시됩니다.
모든 서로 다른 6개 번호 조합의 1등 확률은 같습니다. 특정 통계 패턴이나 필터가 당첨 확률을 높여주지는 않습니다.

내 번호 보관함 · 당첨번호 비교

🎯 회차 지정 · 번호 일치 자동 확인 (v3.1 테스트)
저장 시 다음 회차가 자동 지정됩니다. 당첨 데이터가 업데이트되면 이 브라우저에서 저장된 번호의 일치 결과를 다시 계산합니다. 앱을 닫은 상태에서 푸시 알림은 제공하지 않습니다.
